# adeshgairola.com — Design Context

## Design Philosophy: working notebook, not a brochure

The site is a **working notebook in public**. It should feel lived-in, not polished. Like the back of a practitioner's actual notebook — concrete, dated, unguarded.

The design should visually argue Adesh's content thesis: *security is a habit, not a project.* That means **architecture, not alarm**; **structure, not chrome**; **dynamic content, not maintained brochures**.

## Design Context

### Users

Three audiences, all skim before they read:

1. **Builders / security practitioners** — landed via LinkedIn, an AI Engineer talk, or a Google search for AI security topics. Want a quick read on credibility, then access to writing or open-source projects.
2. **Conference organisers / podcast hosts / journalists** — researching for a speaking ask, podcast invite, or quote. Need bio, photo, contact, recent talks, in <60 seconds.
3. **Hiring managers / recruiters / potential design partners** — vetting credibility for a meaningful engagement (raxIT design partner, advisor role). Need credentials, scale of past work, current focus.

The job to be done: **"Tell me who Adesh is, what he's actually shipped, and where I can hear his voice — fast, with no marketing veneer."**

### Brand Personality

The user picked all four personality sets in the discovery questions, which reads as:

> **Direct, opinionated, considered, builder-energy.**

Not "minimal because I have nothing to say" — minimal because every word and visual element has earned its place. Both **sharp** (will call out industry BS) and **considered** (not noisy or attention-seeking).

Voice signatures already in the content:
- Bracket-titled posts (LinkedIn-style: `[TRUST ME BRO is not a security control]`)
- Sign-off `— A`
- Direct rhetorical questions ("What protects the system while I'm AFK?")
- Numbered specifics (`$4M`, `150+ engagements`, `30 engineers`)
- The line "security is a habit, not a project"

### Aesthetic Direction

**Reference (positive):** [leerob.com](https://leerob.com) — minimal, content-first, serif body, single column. *But* with more content density and more visible character (Adesh has 20+ years of substance to show; leerob is a writer-creator, Adesh is a builder).

**Anti-references (vetoed):**
- Generic CISO / security-firm site (red+grey corporate, hexagon icons, "Trusted by" logo bars, fear messaging)
- Glossy AI-startup landing page (gradient meshes, glass cards, animated hero, "future of AI" copy)
- Designer-portfolio peacocking (heavy animations, scroll-jack, custom cursors, big-typography-as-substitute-for-content)

**Visual reference:** [Vercel design system](https://vercel.com) — adopted as the craft / discipline reference. The user explicitly chose this language. Specifics borrowed:
- **Geist Sans + Geist Mono** typography (Vercel's open-sourced font system)
- **Aggressive negative letter-spacing** at display sizes (-2.4px to -2.88px at 48px) — "compression as identity"
- **Three-weight system only:** 400 (body) / 500 (UI) / 600 (headings). No 700 bold.
- **OpenType `liga`** enabled globally (structural ligatures)
- **Shadow-as-border technique:** `box-shadow: 0 0 0 1px rgba(0,0,0,0.08)` instead of CSS `border`
- **Achromatic palette discipline** — `#171717` text (not pure `#000`), `#ffffff` bg, gray scale `#fafafa → #171717` for everything else
- **Generous whitespace** ("gallery emptiness") between sections

**Theme tokens:**
- Background: pure white `#ffffff` (light) / near-black `#0a0a0a` (dark)
- Text: Vercel near-black `#171717` (light) / off-white `#ededed` (dark)
- Accent: cobalt `#2b5bc4` (light) / lifted cobalt `#6a92e8` (dark) — single semantic accent, no workflow trio
- Rule / divider: `#ebebeb` (Vercel gray-100) / `#262626` (dark)
- Typography: Geist Variable + Geist Mono Variable (single font family)
- Both light + dark mode via `prefers-color-scheme`

**Departure from Vercel:** we don't use Ship Red / Preview Pink / Develop Blue. Vercel uses three workflow accents because they have three product stages. We have one identity (Adesh's voice), so we have one accent (cobalt) doing all the semantic work — links, brackets around post titles, code-block left rules, focus rings.

### Design Principles

These guide every design decision on this project:

1. **Information architecture IS the design.** Section weight, order, and reading rhythm do the work. Decoration only when it sharpens meaning.

2. **Concrete beats abstract.** Numbers, dollar figures, dates, named tools, named patterns. If a sentence could appear on any AI-security-startup page, cut it.

3. **Cobalt earns its place.** The accent does semantic work — links, brackets around post titles, code-block left rules, philosophy pull-quote rule. Never decorative.

4. **Typography over chrome.** Character comes from typeset moves: italic pull-quotes, bracket titles, monospace meta, drop-caps where they earn attention. Not from cards, shadows, gradients, animations, or scroll effects.

5. **Dynamic where possible, hardcoded only when curated.** Recent writing flows from RSS feeds at build time. Static is reserved for items that need editorial judgment (Selected Work, Philosophy, Currently). The site should not become a maintenance burden.

6. **Lived-in, not polished.** Honest dating on every dated thing. Imperfection is texture; airtight perfection is suspicious. Show the work, including what's in-progress.

7. **Scanning-first, depth-on-demand.** Top of the page = identity + current focus + voice in 10 seconds. Detail (Selected Work entries, Background table, credentials) is for the curious — present but not in the way.

### Anti-patterns (what NOT to add)

- Pure black-on-white (matches anti-ref: standard Notion minimalism)
- Multi-color accent palette (cobalt only — adding green/red dilutes the signature)
- Card-based layouts (treats sections as commodities; we want editorial flow)
- Animated reveals on scroll (peacocking)
- Big hero typography that says nothing ("AI Security." in 120px)
- "Trusted by" logo bars (corporate-CISO trope)
- Sticky navigation, mega-menus, breadcrumbs (one-page site, doesn't need them)
- Gradient backgrounds, glass-morphism, drop shadows on body content
- Custom cursors, page transitions, mouse-trail effects
- Generic icon sets (Lucide skeumorphic icons, etc.) — if we need a glyph, use a typographic one (`◇`, `·`, `—`)

### Open questions for next design pass

The user said the current design is "too plain" and "too dense to scan." The fix isn't more decoration — it's **stronger typographic moves**:

- A more dramatic top-of-page treatment (bigger H1 + tagline that hooks in 3 seconds)
- Variable section weight (some sections deserve 2x visual prominence; others should tuck)
- A signature visual element (a recurring motif — possibly the diamond glyph used more deliberately, or a margin-mark, or a horizontal rule with character)
- More italic and weight contrast (Fraunces variable axes underused so far)
- A "currently / now playing / now reading" live detail (matches dynamic philosophy)
- Better section-to-section rhythm — long sections (Selected Work) need internal hierarchy
